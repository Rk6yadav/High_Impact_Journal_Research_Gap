# High_Impact_Journal_Research_Gap

Curated high-impact-factor **SCI / SCIE (Web of Science)** peer-reviewed journal papers supporting research on **AI/ML-Driven Automated Webpage Design & HTML/CSS/JS Code Generation** (using LLMs, MLLMs, Diffusion Models, Transformers, GNNs, and Reinforcement Learning).

## Deliverables

- **[`SCI_High_Impact_Papers.xlsx`](./SCI_High_Impact_Papers.xlsx)** — Formatted multi-sheet Excel workbook containing all **50 verified SCI / SCIE journal papers** (2019–2026) with clickable DOI hyperlinks, color-coded quartiles, auto-filters, plus dynamic **Journal & IF Summary** and **Research Gap Mapping** tabs.
- **[`SCI_High_Impact_Papers.csv`](./SCI_High_Impact_Papers.csv)** — Flat UTF-8 CSV export (all 50 papers, 14 columns including key contributions and DOI URLs) for Excel, Google Sheets, R/Python, or Word import.
- **[`SCI_High_Impact_Papers_Table.md`](./SCI_High_Impact_Papers_Table.md)** — Full categorized Markdown report of all 50 SCI / SCIE papers, journal IF table, and gap-mapping matrix.
- **[`references.bib`](./references.bib)** — Ready-to-use BibTeX entries for all 50 SCI / SCIE papers (LaTeX / Overleaf / Zotero / Mendeley).
